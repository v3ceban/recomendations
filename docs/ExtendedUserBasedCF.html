Class: ExtendedUserBasedCF

ExtendedUserBasedCF(extensionType)

Extended User-Based Collaborative Filtering with advanced features: 1. Inverse User Frequency - Weights rare item ratings more strongly 2. Case Modification - Adjusts similarity based on number of common items
